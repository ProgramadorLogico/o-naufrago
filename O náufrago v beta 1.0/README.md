Bem-vindo ou bem-vinda a versção alpha 1.5 do O Náufrago, aproveitem 
está versão e siga o passo a passo abaixo:

Siga o passo a passo para executar o projeto:
	Arquivo .jar:
		1.	Baixe o arquivo .jar
		2.	Abra o terminal
		3.	Execute este comando: java -jar "O náufrago.jar"
		4.	Aproveite o jogo
			Recado: Certifique-se de estar na mesma pasta que o .jar, ou
		rode o comando com o caminho.

	Arquivo executável:
		1. Baixe o executável
		2. Abra a pasta onde o executável se encontra
		3. Abra o terminal
		4. Deixe a pasta do jogo e o terminal lado a lado
		5. Arraste o arquivo executável da pasta para o terminal
		5. Um texto deve aparecer, se não aparecer, tente denovo
		6. Aperte enter e aproveite
